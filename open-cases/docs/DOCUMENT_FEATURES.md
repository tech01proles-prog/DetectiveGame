# Документальные улики и ложные документы

## Обзор

Реализована система реалистичных документов с текстурами бумаги, штампами и поддержкой ложных улик для повышения сложности расследования.

## Типы текстур документов

### 1. Старая бумага (`old_paper`)
- Желтоватый оттенок с эффектом старения
- Моноширинный шрифт DM Mono
- Шумовая текстура для реализма
- Эффект виньетки по краям

### 2. Новая бумага (`new_paper`)
- Чистый белый фон
- Шрифт Inter
- Минималистичный дизайн

### 3. Фотография (`photo`)
- Тёмный фон
- Белая рамка как у Polaroid
- Светлый текст

### 4. Чек (`receipt`)
- Термоэффект бумаги
- Моноширинный шрифт
- Пунктирные края

### 5. Официальный документ (`official`)
- Формальный стиль
- Двойная рамка
- Шрифт Times New Roman

## Штампы

Документы могут иметь штампы:
```json
{
  "stampText": "CONFIDENTIAL",
  "stampColor": "#dc2626"
}
```

Штамп отображается под углом -15° по центру документа.

## Ложные документы

Ложные улики помечаются флагом `isFalseDocument`:
- Красный бейдж "ЛОЖНЫЙ ДОКУМЕНТ"
- Специальная подсветка модального окна
- Не влияют на решение дела

## Сохранение прогресса

### Автоматическое сохранение
- Сохранение происходит каждые 500мс при изменении состояния
- При закрытии вкладки/обновлении страницы
- Используется localStorage с ключом `open-cases-scenario-{id}-slot0-v1`

### Восстановление после обновления
- При загрузке игры автоматически проверяется наличие сохранения
- Прогресс восстанавливается без вмешательства игрока
- Сохраняются все найденные улики, посещённые локации, диалоги

### API для работы с сохранениями

```typescript
// Загрузка сохранения
import { loadGame } from '@/game/engine';
const savedState = loadGame(scenarioId, slotIndex);

// Сохранение (автоматически debounce)
import { saveGame } from '@/game/engine';
saveGame(gameState);

// Немедленное сохранение
saveGame(gameState, true);

// Очистка сохранения
import { clearSave } from '@/game/engine';
clearSave(scenarioId, slotIndex);

// Получение всех сохранений для сценария
import { getSavesForScenario } from '@/game/engine';
const saves = getSavesForScenario(scenarioId);
```

## Рекомендации по созданию сценариев

1. **Используйте ложные улики умеренно** - 2-3 на сценарий достаточно
2. **Сочетайте текстуры документов** для визуального разнообразия
3. **Штампы добавляйте только к важным документам**
4. **Тестируйте сценарий** на предмет логической целостности
