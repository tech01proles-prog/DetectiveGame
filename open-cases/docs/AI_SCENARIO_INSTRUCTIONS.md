# Инструкция для AI по созданию сценариев Open Cases

## Структура сценария

Каждое дело (scenario) состоит из JSON-файла и набора изображений.

### 1. Карта и координаты локаций

**Важно:** При создании карты AI должен:
1. Сначала нарисовать/сгенерировать карту города (map-bg.png)
2. Продумать расположение ключевых точек на карте
3. Для каждой локации указать координаты в формате **процентов (0-100)** от размера карты

#### Формат координат в scenario.json:

```json
{
  "locations": [
    {
      "id": "bennett_home",
      "title": "Дом Беннеттов",
      ...
      "coordinates": {
        "x": 35,
        "y": 30
      }
    }
  ]
}
```

Где:
- `x`: процент по горизонтали (0 = левый край, 100 = правый край)
- `y`: процент по вертикали (0 = верхний край, 100 = нижний край)

#### Пример расстановки точек:

Если AI рисует карту Сиэтла и размещает:
- Дом Беннеттов в жилом районе на северо-западе → `"coordinates": {"x": 35, "y": 30}`
- Школу на северо-востоке → `"coordinates": {"x": 52, "y": 20}`
- Склад на промышленном юге → `"coordinates": {"x": 40, "y": 80}`

### 2. MapTemplateId

В корне JSON укажите ID шаблона карты:

```json
{
  "mapTemplateId": "case_001_seattle"
}
```

Это связывает сценарий с настройками карты в `src/game/maps/templates.ts`.

### 3. Фоновое изображение

Файл карты должен называться `map-bg.png` и лежать в папке сценария:
```
/scenarios/case-001/map-bg.png
```

В templates.ts для этого шаблона укажите:
```typescript
{
  id: 'case_001_seattle',
  backgroundImage: 'map-bg.png',
  locationCoordinates: {
    // Запасные координаты, если не указаны в JSON
    'bennett_home': { x: 280, y: 120 },
    ...
  }
}
```

## Рекомендации для AI при генерации карты

1. **Композиция**: Распределяйте локации равномерно по карте, избегая скученности
2. **Логика**: Размещайте связанные локации рядом (школа и дом, склад и промзона)
3. **Визуальные ориентиры**: Добавьте реки, парки, основные дороги для навигации
4. **Масштаб**: Учитывайте, что координаты будут конвертироваться в пиксели SVG (800x400)

## Проверка

Перед финализацией убедитесь:
- [ ] Все локации имеют поле `coordinates` с x и y (0-100)
- [ ] mapTemplateId указан и соответствует шаблону в templates.ts
- [ ] map-bg.png существует в папке сценария
- [ ] Координаты логично соответствуют визуальному расположению на карте
