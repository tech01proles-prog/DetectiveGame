# Доска расследования (Investigation Board)

## Описание

Доска расследования — это интерактивное пространство в стиле детективных досок, где игрок может:
- Размещать улики и персонажей в виде стикеров
- Перемещать их по доске
- Соединять красной нитью для установления связей
- Использовать различные цвета для категоризации

## Как использовать

### 1. Открытие доски
- В левой панели навигации нажмите на вкладку **«Доска»** (иконка стикера)
- Основное окно переключится с карты города на деревянную доску

### 2. Добавление элементов
- В левой панели отображаются найденные улики и опрошенные персонажи
- Кликните на улику или персонажа, чтобы добавить их на доску
- Элемент появляется в случайном месте доски

### 3. Перемещение
- Выберите инструмент **«Выбор»** (V)
- Перетаскивайте стикеры мышкой для изменения их положения

### 4. Создание связей
- Выберите инструмент **«Связать»** (C)
- Кликните на первый элемент, затем на второй
- Между ними появится красная пунктирная нить
- Система автоматически проверяет логичность связей

### 5. Цветовая маркировка
- В панели инструментов доступны 6 цветов для стикеров
- Используйте разные цвета для категоризации улик

### 6. Навигация
- **Колесо мыши**: масштабирование
- **Alt + перетаскивание**: панорамирование доски
- Кнопки **+/-** на панели для изменения масштаба
- Кнопка **⟲** сбрасывает масштаб и позицию

## Интерфейс

### Панель инструментов
- **Выбор** — режим перемещения элементов
- **Связать** — режим создания соединений
- **Цветовые кнопки** — выбор цвета для новых улик
- **Масштаб** — управление зумом

### Палитра элементов
- **Улики** — все найденные улики
- **Персонажи** — все опрошенные персонажи
- Индикатор «added» показывает уже размещённые элементы

### Статусная строка
Отображает:
- Количество улик на доске
- Количество персонажей
- Количество соединений
- Режим соединения (если активен)

## Советы по использованию

1. **Начинайте с ключевых улик** — разместите сначала наиболее важные доказательства
2. **Группируйте по цвету** — используйте один цвет для улик из одной локации
3. **Создавайте цепочки** — соединяйте улики в логические последовательности
4. **Проверяйте связи** — система предупреждает о нелогичных соединениях
5. **Используйте зум** — при большом количестве элементов уменьшите масштаб для обзора

## Технические детали

### Хранение данных
Состояние доски сохраняется в `GameState.investigationBoard`:
```typescript
interface InvestigationBoard {
  nodes: BoardNode[];
  connections: BoardConnection[];
  selectedTool: 'select' | 'connect';
}
```

### Автоматическое сохранение
Доска автоматически сохраняется вместе с состоянием игры каждые несколько секунд.

### Валидация соединений
Система проверяет:
- Нельзя соединить элемент сам с собой
- Нельзя создать дублирующее соединение
- Персонаж-персонаж соединения не рекомендуются
- Связанные элементы помечаются как «Связано»

## Вкладка «Доска» в правой панели

В правой панели также доступна информационная вкладка «Доска», которая показывает:
- Сводную статистику по элементам на доске
- Подсказки по использованию
- Список размещённых элементов

Это полезно для быстрого обзора без переключения основного окна.
