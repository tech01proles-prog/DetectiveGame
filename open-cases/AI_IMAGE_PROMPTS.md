# Промпты для генерации изображений в стиле нуарного детектива

## Стиль для всех изображений
**Общий стиль**: Карикатурные нуарные детективные иллюстрации в стиле комиксов 1940-50х годов. 
- Цветовая палитра: приглушенные тона с акцентами янтарного, золотистого освещения (как от уличных фонарей)
- Техника: контурная рисовка с тенями, напоминающая гравюры или литографии
- Настроение: мрачное, таинственное, с драматическим освещением
- Размер: все изображения должны быть одинакового размера (например, 512x512 или 1024x1024)
- Качество: высокое, четкие детали, несмотря на малый размер

## 💡 Советы по использованию:

1. **Пакетная генерация**: Для генерации нескольких изображений за раз используйте один промпт с вариациями:
   ```
   [базовый промпт], character sheet showing 4 different professions: firefighter, policeman, doctor, barber, each in separate panel, consistent noir comic style --ar 2:1 --style raw --v 6
   ```

2. **Единообразие**: Используйте одинаковые параметры `--ar`, `--style`, `--v` для всех изображений чтобы сохранить консистентность.

3. **Качество**: Для маленьких иконок (портреты) достаточно 512x512, для локаций лучше 1024x576 (16:9).

4. **Цветокоррекция**: После генерации можно применить единый фильтр для всех изображений для большей согласованности.

5. **Серийность**: Генерируйте сначала всех персонажей одним батчем, потом все локации другим — это обеспечит лучший стиль-консистенси.
