# Open Cases — «Тишина на Мэдисон»

Базовая бесплатная версия браузерной детективной игры.

## Что уже есть

- 1 полноценное расследование о похищении подростка.
- Реальная география Сиэтла через Leaflet.
- Переключение «Спутник / Схема».
- Десятки потенциальных точек на карте (в первой версии — 7 сюжетных точек, архитектура рассчитана на десятки).
- Постепенное открытие локаций по найденным уликам.
- Персонажи с портретами, отношениями и показаниями.
- Улики с описанием, подробным содержанием и связями.
- Хронология.
- Рабочий блокнот.
- Автосохранение в localStorage.
- Финальная версия расследования с оценкой.
- UI для 1–6 игроков, рассчитанный на совместное обсуждение за одним экраном/звонком.
- Адаптация для мобильного экрана.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Карта

Leaflet подключён через CDN в `index.html`.

В режиме «Схема» используются тайлы OpenStreetMap.
В режиме «Спутник» используются ArcGIS World Imagery.

Перед публичным коммерческим запуском нужно проверить актуальные условия использования выбранного картографического провайдера и при необходимости заменить URL тайлов на собственный/разрешённый источник.

## Где лежит сценарий

Вся игровая логика и контент вынесены в:

- `src/game/data.ts` — сценарий, персонажи, локации, улики, хронология.
- `src/game/types.ts` — типы.
- `src/game/engine.ts` — сохранение, открытие локаций, действия и подсчёт результата.

Это сделано намеренно: следующий сценарий можно добавить как отдельный набор данных, не переписывая весь UI.

## Важное

Портреты и фотографии в этой версии загружаются с Unsplash по URL. Для самостоятельного публичного проекта лучше заменить их на собственный набор лицензированных или сгенерированных ассетов и хранить их локально в `public/assets`.

Карта и сценарий полностью самостоятельные и не используют тексты или персонажей из «Кода города».
