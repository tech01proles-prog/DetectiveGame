# Open Cases — Детективная браузерная игра

Бесплатная браузерная детективная игра с интерактивной картой, системой улик и расследований.

## 🎯 Новые сценарии

### «Тень на Мэдисон» — флагманский сценарий

Полностью новое расследование с проработанной историей и механиками:

**Сюжет:**
- Главный злодей — **Виктор Кросс**, харизматичный манипулятор с тёмным прошлым
- Логичная цепочка из **24 улик**, ведущих к разоблачению
- **9 проработанных персонажей** с уникальными мотивами и секретами
- **7 локаций** для расследования в центре Сиэтла
- **15 событий** в хронологии преступления
- **24 диалоговых узла** с ветвлениями в зависимости от найденных улик

**Особенности сценария:**
- Нелинейное повествование с несколькими путями прохождения
- Система ложных улик (Red Herrings) для усложнения расследования
- Фальшивый чек Виктора как ключевая улика-подделка
- Визуальная индикация ложных документов

## ✨ Ключевые улучшения

### 1. Реалистичные документы

**5 типов текстур:**
- `old_paper` — состаренная бумага для старых документов
- `new_paper` — обычная бумага для современных документов
- `photo` — фотобумага для снимков
- `receipt` — термобумага для чеков
- `official` — бланки официальных документов

**Визуальные штампы:**
- Настраиваемый текст штампа
- Выбор цвета (красный, синий, чёрный)
- Различные типы штампов: "СЕКРЕТНО", "КОПИЯ", "ПОДЛИННИК", "УЛИКА"

**Типографика:**
- Моноширинные шрифты для чеков и старых документов
- Рукописные шрифты для заметок
- Официальные шрифты для документов

### 2. Система ложных улик (Red Herrings)

- Фальшивые документы в сюжете
- Визуальная индикация подделок (при открытии)
- Механика проверки подлинности через другие улики
- Влияние на финальную оценку расследования

### 3. Автосохранение прогресса

- Сохранение каждые **500мс** во время игры
- Авто-восстановление после перезагрузки страницы
- Исправлена кнопка "Продолжить" в главном меню
- Сохранение текущего состояния расследования, найденных улик и заметок

### 4. Улучшения геймплея

**Диалоги:**
- Диалоги не закрываются автоматически — игрок контролирует темп
- Выбранные реплики помечаются серым цветом для отслеживания пути
- Ветвление диалогов в зависимости от найденных улик

**Интерактивная доска расследования:**
- Визуальное связывание улик между собой
- Отметка важных соединений
- Экспорт теории для финального обвинения

**Система требований к уликам:**
- Некоторые диалоги открываются только при наличии определённых улик
- Персонажи реагируют на предъявленные доказательства
- Возможность обвинения с разными уровнями доказательств

## 🔥 Новые механики (v2.0)

### 1. Система дедукции

**Соединение улик для создания новых фактов:**
- Игрок соединяет связанные улики на доске расследования
- Автоматическая проверка логичности связей
- Открытие новых фактов при правильных deduction
- Влияние на профиль подозреваемых

**Примеры дедукций:**
- "Фотография + Журнал доступа = Подтверждение присутствия"
- "Чек + Свидетельство = Ложное алиби"

### 2. Шкала доверия персонажей

**Динамические отношения:**
- Каждое взаимодействие влияет на доверие (0–100)
- Высокое доверие открывает эксклюзивные диалоги
- Низкое доверие блокирует важные вопросы
- Визуальный индикатор доверия в профиле персонажа

**Механика:**
- Дружелюбные реплики: +10–20 доверия
- Агрессивные вопросы: -10–30 доверия
- Предъявление улик: ±доверие в зависимости от ситуации

### 3. Динамическое время

**Система времени в реальном времени:**
- Каждое действие тратит игровые минуты
- Некоторые улики исчезают после определённого времени
- Критические события происходят по расписанию
- Давление времени усложняет принятие решений

**Особенности:**
- Отображение текущего времени в интерфейсе
- Таймер для сценариев с ограничением по времени
- События, зависящие от времени суток

### 4. Профили персонажей

**Автоматически обновляемые досье:**
- Фотография и базовая информация
- Зафиксированное алиби с статусом проверки
- Обнаруженные мотивы и секреты
- История изменений статуса
- Текущий уровень подозрения (0–100)
- Связи с другими персонажами

**Функции:**
- Автоматическое обновление при находке улик
- Отслеживание истории допросов
- Визуализация сети связей между персонажами

### 5. Атмосферные эффекты

**Погружение в детективную атмосферу:**
- Динамическое освещение локаций
- Изменение погоды в зависимости от сюжета
- Звуковое сопровождение (шаги, скрип дверей, телефонные звонки)
- Эффекты старого фильма для флешбэков

**Настройки:**
- Регулировка громкости ambient-звуков
- Включение/выключение визуальных эффектов
- Режим "фокусировки" для снижения отвлекающих факторов

## 🗺️ Карта

Leaflet подключён через CDN в `index.html`.

В режиме «Схема» используются тайлы OpenStreetMap.
В режиме «Спутник» используются ArcGIS World Imagery.

Перед публичным коммерческим запуском нужно проверить актуальные условия использования выбранного картографического провайдера и при необходимости заменить URL тайлов на собственный/разрешённый источник.

## 📁 Структура проекта

### Где лежит сценарий

Вся игровая логика и контент вынесены в:

- `src/game/data.ts` — сценарий, персонажи, локации, улики, хронология
- `src/game/types.ts` — типы данных
- `src/game/engine.ts` — сохранение, открытие локаций, действия и подсчёт результата
- `public/scenarios/` — загружаемые JSON сценарии

Это сделано намеренно: следующий сценарий можно добавить как отдельный набор данных, не переписывая весь UI.

### Документы и инструкции

- `docs/AI_SCENARIO_INSTRUCTIONS.md` — инструкция по созданию сценариев с помощью ИИ
- `docs/DOCUMENT_FEATURES.md` — документация по системе документов
- `docs/INVESTIGATION_BOARD.md` — руководство по доске расследования
- `public/scenarios/README.md` — система загрузки сценариев
- `AI_IMAGE_PROMPTS.md` — промпты для генерации изображений

---

## ⚠️ Важное

Портреты и фотографии в этой версии загружаются с Unsplash по URL. Для самостоятельного публичного проекта лучше заменить их на собственный набор лицензированных или сгенерированных ассетов и хранить их локально в `public/assets`.

Карта и сценарии полностью самостоятельные и не используют тексты или персонажей из «Кода города».

## 🎮 Как играть

1. Выберите сценарий в главном меню
2. Исследуйте карту, открывая локации
3. Находите улики и изучайте их содержание
4. Беседуйте с персонажами, выбирая реплики
5. Связывайте улики на доске расследования
6. Сделайте финальное обвинение, указав преступника, мотив и метод

**Совет:** Внимательно изучайте документы — некоторые могут быть подделками!
